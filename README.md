## Installation
Please ensure that your device meets the following requirements before installation:
- Running iOS/iPadOS 16.0 or later (this includes 27 betas).
- Not managed by a school, workspace, or other organization (MDM).
- Device is a personal one supervised by yourself.

And that these things can be done as well:
- You will need a mac or a PC in order to supervise your device. This can be done very easily with [Nugget](https://github.com/leminlimez/Nugget), but please note that Nugget no longer works properly on iOS 27 and later.
- You will also need a sideloading method of your choice to use this tool. Almost all methods of sideloading, including TrollStore and LiveContainer, are supported.

## Usage
- Tweaks are applied using configuration profiles generated by the app. Change your settings in the tweak page of your choice, and hit "Install Profile." Make sure you only install one profile at a time.
- To see the tweaks you've installed, or to remove tweaks, go to Settings > General > VPN & Device Management.
- To export profiles, use the "Profile Viewer" tool in the top-right corner.
